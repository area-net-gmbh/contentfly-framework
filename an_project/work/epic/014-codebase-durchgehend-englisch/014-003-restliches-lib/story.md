# Restliches Framework-Paket auf Englisch

## Goal
Alles in `lib/contentfly/`, was nach Kernel und Security übrig ist, ist englisch: `Classes/Api.php`,
Controller, Provider, Manager, Types, ORM, File, Events, Exceptions, `Config.php`,
`Helper.php`, `Messages.php`, `Command/` (einschließlich `appcms:provider:sync`),
`Migration/` (`RemovedAttributeFieldsRector`), `composer.json` (`description`,
`extra.hinweis`, `suggest`) und `config.sample.php`.

Am Ende findet die Suche in ganz `lib/` kein deutsches Wort mehr.
