# Bekannte Deprecations, die das Gate aus 006-005-0003 durchlaesst.
#
# Format je Zeile, mit "|" getrennt:
#
#     <datei relativ zur Projektwurzel>|<Anfang der Meldung>|<Begruendung + aufloesendes Ticket>
#
# Leerzeilen und Zeilen mit fuehrendem # werden uebersprungen.
#
# ── Die Regeln, nach denen hier etwas landet ──────────────────────────────────────────
#
# 1. EINE NEUE MELDUNG MACHT DEN LAUF ROT. Diese Liste ist die Ausnahme, nicht der Weg.
#    Wer hier eintraegt, statt zu beheben, braucht einen Grund und ein Ticket.
#
# 2. JEDE ZEILE NENNT, WAS SIE AUFLOEST. Ohne benanntes Ticket oder Epic ist es keine
#    Ausnahme, sondern ein abgeschaltetes Gate — dieselbe Regel wie bei den
#    Audit-Ausnahmen in composer.json (006-005-0001).
#
# 3. EINE ZEILE, DIE NICHT MEHR GREIFT, MACHT DEN LAUF EBENFALLS ROT. Verschwindet eine
#    Meldung, gehoert ihre Ausnahme gestrichen. Sonst bliebe eine Erlaubnis ins Leere
#    stehen, die spaeter stillschweigend wieder greift (006-005-0002 macht dasselbe fuer
#    die CVE-Ausnahmen).
#
# 4. SCHLUESSEL IST DATEI + MELDUNG, NICHT DIE ZEILENNUMMER. Auf PHP 8.3 ergaben 148
#    protokollierte Zeilen genau VIER solcher Paare — die Zeilennummer haette die Liste
#    bei jeder Codeaenderung brechen lassen.
#
# ── Stand bei der Einrichtung (PHP 8.3, gemessen in 006-005-0003) ─────────────────────
#
#   148 protokollierte Zeilen, 21 eindeutige Meldungen, 4 Paare aus Datei und Meldung.
#   Davon 12 Zeilen aus Silex, 9 aus eigenem Code.
#
# ── Stand nach 000-000-0023 ───────────────────────────────────────────────────────────
#
#   Die drei Eintraege aus eigenem Code sind behoben und deshalb hier gestrichen — das
#   Gate hat sie selbst als abgelaufen gemeldet und die Streichung eingefordert, genau
#   wie Regel 3 es vorsieht. Uebrig bleibt EINE Ausnahme, die aus Silex.
#
#   Damit steht die Liste auf genau einer Ursache: einem Fremdpaket, das mit Epic 009
#   faellt. Waechst sie wieder, ist das eine Aussage und keine Gewohnheit.
#
# ── Stand nach 009-002-0006: LEER ─────────────────────────────────────────────────────
#
#   Die letzte Ausnahme betraf Silex' ExceptionListenerWrapper. Silex ist mit dem
#   Kernel-Schnitt aus dem Baum, und das Gate hat die Streichung selbst eingefordert:
#
#       Die Meldung tritt nicht mehr auf — der Grund fuer die Ausnahme ist entfallen.
#       ZU TUN: die Zeile aus tools/ci/deprecations-ausnahmen.txt streichen.
#
#   Genau so war Regel 3 gemeint. Die Datei bleibt mit ihren Regeln stehen, ohne einen
#   einzigen Eintrag — das ist der Zustand, den Epic 009 herstellen sollte, und die naechste
#   Zeile hier ist wieder eine Aussage.
